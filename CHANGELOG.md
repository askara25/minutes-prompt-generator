# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-09-23

### Added

- Five-step welcome and workflow card
- Required meeting topic, date, time, venue, and attendees fields
- Optional meeting context and minutes-style settings
- Recommended verification and accuracy controls
- High-contrast selected states and keyboard focus indicators
- Required-field validation with clear feedback
- Prompt generation, copy, reset, and text-download feedback
- Four-stage AI workflow: request, extract, verify, and generate
- Responsive standalone HTML implementation
- Local browser operation without external dependencies
